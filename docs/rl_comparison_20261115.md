# 수익률 기반 월간 비교군·실제 ANOVA 연결 — 2026-11-15

`compare-rl`로 **PPO 36개, 월간 MVO·동일가중 8개, 일간 동일가중 대조군 4개**를 실행했다.
기존 CSV를 새 월간 비교군과 합치지 않고, 동일한 로컬 실행 커널에서 얻은 수익률만 통계 표본으로 썼다.
ANOVA 1·2·3과 Holm 계산은 완료됐지만, 전체 평가는 **잠정 상태**다.
PPO 한 개의 기존 CSV 대조가 엄격한 허용오차를 넘었고, 가격·공통통화·FX·RF·시장별 시각 검증은 남아 있다.

## 실행 프로필

새 프로필은 `rl_return_comparison_monthly_v1`이다. 기존 참조 백테스터의 다음 종가 체결 프로필과 다르다.

| 항목 | 이번 실행 |
| --- | --- |
| 자산·입력 | 원본 12개 자산 순서, 같은 구간 피처·정규화 전 로그수익률 |
| 손익 | 로그수익률을 `expm1`으로 변환, 목표 비중으로 다음 관측일 수익 적용 |
| 초기자산·비용 | 1,000,000; 회전율은 비중 변화 절댓값 합; 수수료 0.00015 + 슬리피지 0.0005 |
| 평가일 | producer와 같은 19행 prefix, 첫 테스트 관측은 결정에 사용하고 다음 관측일부터 채점 |
| 구간별 일수 | 2022: 259, 2023: 257, 2024: 259, 2025: 258 |
| Safe-Guard | 기존 RL 평가와 같이 비활성화(`mdd_limit=10.0`), 종료 청산비용 추가 없음 |
| PPO | 원래 행동 변환을 그대로 사용, 결정론적 추론, 매일 목표 비중 |
| MVO·월간 EW | 각 월의 첫 **결정일**에 재설정, 해당 결정의 다음 관측일에 손익 기록 |
| MVO | 결정일까지의 최근 252개 단순수익률 공분산, SLSQP, 합 1·공매도 금지·목표 상한 40% |
| 동일가중 구분 | 통계의 `EqualWeight`는 월간. `EqualWeightDailyControl`은 원본 재현 대조용이며 통계에서 제외 |

예를 들어 2월 첫 결정일이 2월 1일이면 그 목표의 첫 수익은 다음 관측일에 기록된다.
첫 테스트 세션의 수익률을 추가하거나 누락된 날짜를 채워 넣지 않았다. 이는 producer 실행을 맞춘 것이며,
전체 거래일을 경제적으로 정확하게 평가했다는 인증은 아니다.

### 월간 보유일과 비중 상한

RL 환경은 행동마다 softmax와 상한 투영을 한다. 현재 보유 비중을 행동으로 역변환하면 작은 오차가 생기며,
40%를 넘은 보유 비중은 강제 조정돼 월간 전략에서도 거래비용이 생긴다.

비교군 전용으로 **격리된 환경 모듈 인스턴스**를 만들고 행동 변환만 입력 비중의 복사로 바꿨다.
`PortfolioEnv.step`의 비용·수익·드리프트·계좌 갱신 코드는 그대로 사용한다. PPO 모듈과 팀 소스 파일은 바꾸지 않는다.
새 목표에는 기존 제약을 검사하고, 보유일에는 float32 보유 비중을 정규화·상한 조정 없이 그대로 넘긴다.
요청한 비중이 실제 목표와 같고, 보유일 회전율이 정확히 0인지 실행 중에도 검사한다.

실제 검증:

- MVO 최적화 **48/48회 수렴**, fallback 0회. 결정별 solver 상태·메시지·반복 수·목적값·자료 시작/종료일 저장.
- 월간 8개 실행의 비리밸런싱일 **1,970행**, 회전율·수수료·슬리피지가 모두 정확히 0.
- MVO 새 목표의 최대 비중은 40%. 보유 중 최대 비중은 약 42.0333%다.
  이는 월간 사이의 가격 변동이며 신규 목표 제약 위반으로 숨기거나 강제 매도하지 않는다.
  매일 보유 비중까지 40% 이하로 유지하는 실험은 별도 프로필이 필요하다.
- 일간 동일가중 4개는 이 어댑터로 실행해 원본 CSV와 기존 허용오차 안에서 일치했다.

## 원본 CSV 대조 — 불일치 1개 보존

대조 기준은 기존과 같은 `atol=1e-8`, `rtol=1e-6`이다. 날짜·수익률·계좌가치·낙폭·회전율·최대 목표비중·벤치마크를 확인한다.

- PPO **35/36개**와 일간 동일가중 **4/4개**가 모든 필드에서 일치했다.
- `ppo_test_w3_simple_s44`: 낙폭의 **2024-11-07, 2024-11-08** 두 행이 허용오차를 초과했다.
- 전체 기간 낙폭 최대 절대차는 `1.2955760842620068e-8`, 일별 수익률 최대 절대차는 `7.631191116519442e-9`다.
- 수익률·계좌가치 등 다른 필드는 통과했다. 플랫폼별 부동소수 연산 차이가 가능한 설명이지만 **원인은 확정하지 않았다**.
- 허용오차를 확대하지 않았다. 해당 실행과 전체 묶음은 `provisional_reference_mismatch`이며, 대조 상세는 `mismatch`다.

새 분석은 **모든 전략의 로컬 재실행 수익률**만 사용한다. 원본의 값을 가져와 불일치 행을 교체하거나 해당 seed를 제거하지 않는다.
따라서 새 프로필 내부의 비교는 가능하지만, 원본 36개 실행을 모두 재현했다고 주장하지 않는다.
이 불일치는 ANOVA 1의 입력에 포함되며, 대표 PPO가 `mdd_l1.0`인 ANOVA 2·3에는 해당 실행이 들어가지 않는다.
`explain-ppo --reference-daily`의 기존 엄격한 중단 동작은 유지한다.

## 실제 월별 표본과 국면

- 2022-01~2025-12, 공통 **48개월**.
- PPO는 실행별 일별 순수익률을 먼저 월별 복리로 집계한 후 같은 월의 3seed를 평균한다.
- 월간 MVO/EW는 월마다 seed 없는 한 건이다. seed 수만큼 복제하지 않는다.
- 원시 월별 표본 **528행**, seed 평균 후 5개 전략 × 48개월 = **240행**.
- 국면은 해당 월 시작일 **이전** SPY 로그수익률 60개 합의 `expm1`으로 판정한다.
  `>+5%` 상승, `<−5%` 하락, 나머지 횡보. 계산에 쓴 날짜와 누적수익률은 `regimes.csv`에 저장한다.
- 상승 23개월·하락 7개월·횡보 18개월. 전략×국면 각 셀의 최소 표본은 7로 내부 최소 6을 충족했다.
- 60개는 공급된 **미국·한국 합집합 달력의 관측 수**다. SPY 휴장일의 0수익률도 포함하며, 미국 거래소 60거래일과 같다고 표시하지 않는다.
- 국면 자료가 부족하거나 잘못되면 검정 3만 `data_invalid`, 검정 1·2는 보존하고 Holm은 `incomplete_family`다.

검정 1·2는 비유의이므로 Tukey 실행 조건 미충족이다. 검정 3은 국면 효과의 원 p<0.05로
기존 규칙에 따라 9개 전략×국면 셀의 Tukey 36쌍을 실행했으며, 유의한 쌍은 **0개**다.
5개 omnibus 효과의 Holm 가족 보정은 `complete`다.

검정 2·3의 Levene p는 각각 약 **0.000499**, **0.006876**으로 등분산 가정에 경고가 있다.
같은 월의 반복 관측과 시계열 의존성도 ANOVA/Tukey로 해소되지 않는다. 국면 효과를 인과관계나 PPO 우월성으로 해석하지 않는다.

보조적으로 연도 내 대응 원형 블록 부트스트랩(1·3·6개월, 각 5,000회)을 저장했다.
3개월 블록에서 PPO−MVO 평균 월수익률 차이는 약 +0.6223%p, 95% 구간은 [−0.1504, +1.3661]%p다.
PPO−월간 EW는 약 −0.3563%p, 95% 구간은 [−0.5445, −0.1604]%p다.
나머지 블록 길이에서도 각각 0 포함/미포함 여부가 같았다. 대응 비교와 ANOVA는 다른 검정이므로 결과를 혼동하지 않는다.
이는 Sharpe +0.2 또는 최종 성능 목표의 판정을 대체하지 않는다.

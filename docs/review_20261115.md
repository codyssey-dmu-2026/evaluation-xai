## 3. `w3/simple/s44` 불일치 조사

### 확정 사실

1. **환경·자료 커널**: 일간 EW 4개는 두 플랫폼 모두 통과. 순수익률 최대 차이 3.5e-18~6.9e-18(1ulp 수준).
   신경망이 없는 경로는 사실상 동일하므로 입력 파일·날짜 정렬·비용·드리프트 계산 차이로 보기 어렵다.
2. **모든 PPO 실행이 첫 채점일부터 다름**: `w3/simple/s44`의 259행 전부 순수익률이 1e-12 이상 차이(Mac·Linux 모두).
   리뷰 Linux 60개 실행 중 CSV와 비트 동일한 실행은 0개.
3. **오차 크기**: 최대 목표비중 오차 4.8e-8~1.65e-7(float32 기계 epsilon 1.19e-7 수준), 월수익률 최대 오차 2.6e-9~1.5e-8.
   Mac 불일치 실행의 월수익률 최대 오차는 6.0e-9.
4. **불일치 실행이 플랫폼마다 다름**: Mac은 `w3/simple/s44`, 리뷰 Linux는 다른 3개. `w3/simple/s44`의 낙폭 최대 오차는 Mac 1.30e-8, Linux 5.04e-9.
5. **실패 위치는 낙폭이 작은 날**: 2024-11-07 낙폭 0.00159일 때 허용치는 1e-8+1e-6×0.00159≈1.16e-8이고 Mac 오차는 1.23e-8.
   계좌가치는 rtol 1e-6 덕분에 같은 상대오차를 허용하지만 낙폭은 거의 atol만 적용된다.
6. **같은 기기 안에서도 같은 크기의 차이**: 같은 모델을 리뷰 Linux에서 float32 배치 계산과 한 행씩 계산하면 비중이 최대 1.33e-7 다르고,
   float32와 float64 계산은 7.6e-8 다르다.

### 가설 (강하게 지지되지만 미확정)

PPO 정책망의 float32 연산이 플랫폼·BLAS 경로마다 1ulp 수준으로 달라지고, 이 차이가 계좌가치에 누적돼
낙폭이 작은 날 엄격한 낙폭 atol을 넘는다.

### 확정하지 못한 것

- 원 producer의 OS·CPU·torch 빌드·스레드 설정을 모른다.
- 어느 플랫폼에서도 CSV를 비트 단위로 재현하지 못했다.

따라서 원인을 "부동소수 오차"로 단정하지 않고 `diagnosis.classification = "unresolved_numeric_difference"`로 둔다.
허용오차(`atol=1e-8`, `rtol=1e-6`)와 원본 CSV는 바꾸지 않았다(`tolerance_changed: false`).

### 통계 사용 정책 검토

현행 정책(로컬 재실행 수익률만 사용, CSV 행 대체·seed 제거 없음)을 유지한다. 근거:

- CSV 행으로 바꾸면 서로 다른 실행 경로가 섞인다.
- 월간 표본에 미치는 차이는 최대 1.5e-8로, 보고 정밀도(소수 6자리)의 F·p에는 영향이 없었다.
  두 플랫폼에서 불일치 실행이 서로 다른데도 ANOVA 값이 같았다.

다만 표시 방식은 보강했다. 각 검정의 `input_reconciliation`이 불일치 실행 포함 여부를 직접 표시하며,
리뷰 Linux 실행에서는 ANOVA 1에 3개가 포함되고 ANOVA 2·3에는 없다.
float32 수준 차이를 별도 허용 범주로 둘지는 팀이 결정할 사항이며, 결정 전까지 `mismatch` 표시를 유지한다.

## 4. 추가 기능

### 재개 가능한 전체 재실행

```bash
PYTHONPATH=src MPLCONFIGDIR=/tmp/codyssey-mpl OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
.venv/bin/python -m evaluation_xai compare-rl \
  --models-dir ../models --processed-dir ../data/processed \
  --rl-source-dir ../rl-engine/src --all-variants \
  --link-explanation artifacts/real-20261112-w1 --link-explanation artifacts/real-20261112-w2 \
  --link-explanation artifacts/real-20261112-w3 --link-explanation artifacts/real-20261112-w4 \
  --output artifacts/<새-폴더>
# 실패·중단 후 같은 명령에 --resume 추가
```

- `--all-variants`: PPO 60개. ANOVA는 사전 지정한 `simple`, `sharpe`, `mdd_l1.0`만 사용하며 결과를 보고 바꾸지 않는다.
  λ=0.5/5.0은 `supplementary_samples.parquet`에 기술용으로만 저장하고 `include_in_anova=false`.
- `run_manifest.json`: 입력·모델·코드·환경·런타임 지문과 시도 기록. `--resume`은 지문이 하나라도 다르면 거부하고
  달라진 항목을 알린다. 이미 게시된 폴더도 재개를 거부한다.
- 완료 실행은 `run.json`의 `artifact_sha256`로 재검증 후 재사용한다. 파일이 바뀌면 중단한다.
- 중단된 `.partial-*` 폴더는 삭제하지 않고 `.abandoned/`로 옮기며, 이전 `failure.json`은 `attempts/failure-N.json`으로 보존한다.

### 공통 run_id / decision_id와 기존 SHAP 연결

- PPO `decisions.json`에 결정 직전 관측값의 SHA-256(`observation_sha256`)을 저장한다. 월별 표본에는
  `run_id`와 해당 월의 첫·마지막 `decision_id`·결과일을 추가했다.
- `--link-explanation`은 기존 `explain-ppo` 묶음을 **재계산 없이** 다음 조건을 모두 만족할 때만 붙인다:
  모델·메타 SHA, 환경 SHA, 피처·수익률·manifest SHA, 같은 결정 날짜, **관측값 비트 동일**,
  설명 비중과 재실행 목표비중 차이 ≤1e-6, 원 묶음의 CSV 대조가 `mismatch`가 아님.
- 실패하면 `explanation_links`에 실패 항목과 함께 `rejected`로 남기고 연결하지 않는다.
- 새 `explain-ppo` 결과는 `observation_sha256`와 런타임도 기록한다.

리뷰 Linux 실행에서는 기존 SHAP 4건이 **모두 거부**됐다. 실패 조건은 `observation_sha256` 하나뿐이었고,
관측 288개 중 차이는 현재 보유 비중 구간(276~287번)에만 있었다(최대 3e-8).
Mac에서는 기존 SHAP 재실행과 `final` 비교 결과의 일별 값이 4개 모두 비트 단위로 같았으므로 연결될 가능성이 높다.
다만 **Mac에서 새 코드로 실행해 확인하지는 않았다.**

| --- | --- | --- |
| `mission_anova` 형식이 import-rl과 다름(`tests.<검정>.status = ok` vs 최상위 `<검정>.status = complete`) | 대시보드 `views/anova.py`는 최상위 키와 `complete`만 완료로 표시 → 새 결과를 연결해도 검정 1·2·3 모두 "결과 대기" | `compare-rl` 번들과 `mission-anova.json`을 import-rl 형식으로 통일. `overall_status`, Holm·불일치 표시 등은 같은 객체에 유지. `anova` CLI 단독 출력 형식은 그대로 |
| 실행 폴더에 `weights.parquet` 없음 | 게이트웨이 `/backtest/{run_id}/timeseries`가 이 파일로 비중 차트를 그림 | 목표 비중을 `weights.parquet`로도 저장(파일 해시 목록 포함) |

검증: 실제 자료로 실행한 결과를 플랫폼 게이트웨이 코드에 그대로 연결해, 대시보드 판정 로직에서 검정 1·2·3 모두 완료,
시계열 응답 200·비중 12열을 확인했다. 통계 값은 변하지 않았다. pytest 160개, Black·flake8·diff 통과.

플랫폼 담당에게 전달할 사항(우리 저장소에서 고칠 수 없는 것):
고정 커밋 갱신, 부트스트랩 라벨 키(`PPO-mdd_l1.0_seed_mean_minus_EqualWeight_monthly`, `..._MVO_monthly`),
2원 ANOVA 항 이름(`C(strategy, Sum)`, `C(regime, Sum)`, 상호작용) 라벨, 검정 3 요약 카드가 첫 효과(전략)만 표시해 유의한 국면 효과가 가려지는 점.

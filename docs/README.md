회의에서는 요약부터 읽고, 수치나 계산 방법에 의견이 있으면 상세 기준서의 해당 절을 함께 확인한다.

## 문서의 지위

1. **과제 필수**: 제공된 과제 원문에서 요구한 사항. 내부 기본값으로 완화하지 않는다.
2. **Evaluation 기본값**: 과제에 없는 집계·반복·처리 방법을 담당자가 정한 기준. 팀 전체의 확정 합의와 구분한다.
3. **연동 확인 필요**: 다른 파트의 데이터나 운영 방식에 따라 먼저 확정해야 하는 항목.
4. **현재 구현**: 실제 저장소 코드의 기능. 목표 문서에 적혀 있다는 이유만으로 구현 완료로 보지 않는다.

계산 방법은 상세 기준서가 기준이고 요약은 안내용이다. 코드와 기준서가 다르면 차이를 기록하고 연동을 보류하거나 별도 버전으로 실행한다. 코드 동작이 과제 요구사항을 자동으로 대체하지 않는다.

이번 작업은 문서 정리다. 기준 원안의 실험 조건을 새로 승인하거나 실제 PPO 성능을 측정한 작업이 아니다. 과제 원문 대조 기준일은 2026-09-26이며, 2026-09-28에 노션을 다시 조회했다는 뜻은 아니다.

## 먼저 확정할 항목

- 최종 투자 자산: 기존 미국 ETF 10개 연구안과 마지막 확인한 혼합 12자산 데이터 구성 사이의 차이.
- 혼합 시장 사용 시 기준통화·환율·시장별 휴장일·가용시각·공통 평가 시각.
- 같은 통화와 평가 구간에 맞는 벤치마크·무위험수익률(RF).
- fold별 전처리기와 PPO 행동→비중 변환, 안전 규칙 전후 기록의 형식.

합의 전에도 합성 데이터로 단위 테스트와 연동 개발은 진행할 수 있다. 다만 실제 성과 판정은 보류한다.

## 변경 기록

| 날짜 | 내용 |
| --- | --- |
| 2026-09-26 | 개인 작성 기준 v1.0: 평가 수치·방법·입출력 목표 정의 |
| 2026-09-28 | 저장소용 요약·상세·구현 차이 문서로 정리. 미국 전용 기본안의 조건부 적용과 미구현 사항 명시. 실행 코드는 변경하지 않음 |

기준을 바꿀 때는 이유, 영향받는 실행, 이미 확인한 테스트 기간, 새 버전을 기록한다. 과거 결과를 새 기준의 결과인 것처럼 덮어쓰지 않는다.

교육용이며 실제 투자 조언에 사용할 수 없다. 백테스트 성과는 미래 수익을 보장하지 않는다.

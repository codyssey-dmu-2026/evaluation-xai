# 코드 리뷰 수정 — 2026-11-13

리뷰에서 재현한 네 가지 입력·부분 실패 문제를 수정했다. 기존 PPO 모델·시장 자료·성과 수치를 변경하지 않았다.

## 거래 시각과 위험 태그

`run_backtest`는 명시적 `execution_schedule` 전체를 정책 호출 전에 검사한다.

- `decision_at`은 직전 가격 세션 날짜, `execution_at`은 현재 가격 세션 날짜와 일치해야 한다.
- 모든 시각에 시간대가 있어야 하며, 결정 < 체결 순서여야 한다.
- 다음 결정은 이전 세션의 체결보다 앞설 수 없다.
- 날짜 판정 시간대는 `session_timezone`으로 지정한다. 생략하면 가격 인덱스의 시간대, 시간대 없는 인덱스라면 UTC를 사용한다.
- 예: 한국 날짜 기준 원장이면 `session_timezone="Asia/Seoul"`. 기록 시각은 기존처럼 UTC로 저장한다.

2024년 가격에 2025년 시각을 붙여 미래 위험 태그를 사용하는 리뷰 사례를 차단한다. 이 검사는 날짜·순서의 일관성 검사이며 실제 거래소 종가 시각, 첫 관측의 정보 가용시각, 혼합 시장 체결 가능성까지 인증하지 않는다. 참조 백테스터는 단일 평가 세션 기준이므로 혼합 시장의 공통 세션 정의는 별도 합의가 필요하다.

## 월별 통계 입력

- `month`는 `YYYY-MM` 문자열 또는 pandas 월별 `Period(freq="M")`만 허용한다. 일별 날짜·Timestamp를 월로 자동 변환하지 않는다.
- 월별 Period는 문자열로 통일한 뒤 같은 `month/strategy/seed`가 중복되는지 검사한다.
- PPO와 그 외 학습 전략은 설정된 모든 seed가 월마다 정확히 한 번 있어야 한다. 미션 CLI 기본 seed는 42·43·44다.
- seed 생략은 MVO·동일가중에만 허용한다. 일반 집계 함수는 `mvo`, `ew`, `equalweight`, `equal_weight`를 대소문자 구분 없이 기준 전략으로 인식한다. 미션 비교의 전략 이름은 기존 `MVO`, `EqualWeight`를 사용한다.
- 기준 전략은 월마다 seed 없는 결과 한 건이어야 한다. seed 수만큼 복제하거나 평균 내지 않는다.
- 월·seed·공통 수익률 자료가 잘못되면 입력 오류로 중단한다. 잘못된 표본으로 p값을 계산하지 않는다.

## 국면 검정의 오류 격리

`regime`에 결측값, 허용되지 않은 값, 같은 월의 상충 값이 있으면:

1. 보상 함수 비교와 전략 비교는 유효한 자료로 계속 실행한다.
2. 국면 검정만 `data_invalid`와 원인을 기록한다.
3. 전체는 `incomplete`, Holm 가족 보정은 `incomplete_family`로 유지한다.
4. CLI는 이 부분 결과를 JSON으로 저장한다. 잘못된 국면을 임의 보완하지 않는다.

국면 열 자체가 없는 경우에는 기존처럼 해당 검정을 미완료로 남긴다.

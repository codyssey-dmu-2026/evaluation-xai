## 기능별 상태

| 영역 | 현재 구현 | 최종 평가 전 남은 작업 |
| --- | --- | --- |
| 데이터 계약 | wide 수정주가와 MarketDataManifest 검사 | 실제 거래일 완전성, 기준통화 변환·가용시각·원본 자료 대조 |
| 12개 지표 | 원장 수익률·RF·벤치마크로 계산, 계산 불가 사유 | 실자료 연결, seed별 전 구간 결합·목표 판정 자동화 |
| 동일가중·MVO | 월간 기준 전략, MVO 제약·수렴 확인·동일가중 대체 기록 | 대체 비율 10% 초과 시 최종 판정 보류, 보조 비교 실험 |
| 거래 원장 | 다음 종가·비용·MDD 청산·현금 유지 모의 원장 | RL 환경과 동일한 체결·비용·종료 동작인지 대조 |
| Walk-Forward | 4년/1년 구간, 구간별 새 학습 함수 호출 | 실제 PPO 완전 재학습·100,000스텝·fold별 scaler·학습 범위 증거 |
| PPO 비교 | 외부 정책 연동 인터페이스 | 3보상×4구간×3seed 모델과 로그. 현재 데모에는 실제 PPO 없음 |
| ANOVA·Tukey | 월별 복리·seed 집계, One-/Two-way·η²·조건부 Tukey·Holm | 실자료 3종 검정, 완전한 월·공통 월 검증, full-rank 확인 |
| 통계 진단 | Shapiro·Levene | Q-Q plot·자기상관·Ljung–Box(lag 3) 기록 |
| 부트스트랩 | NumPy로 연도 내 대응 원형 블록 재표집 | 1/3/6개월 민감도 결과와 경고를 최종 리포트로 묶기 |
| SHAP | 묶음별 Permutation 계산, Summary/Force, 결정론·가산성 검사 | 실제 PPO 함수와 기록 비중 대조, 학습 rollout 배경, seed 안정성 검사 |
| RAG·보너스 | RiskTag 구조와 시각 검사 등 초기 계약 | 태그→관측/규칙→최종 비중 end-to-end, 4개 보너스 실측 |
| API | /health, /backtest, /explain 사전 계산 조회 | 목표 필터·메타데이터 전체, 신규 결정 설명, 5초 실측 |
| 산출물 | 합성 데모 결과·원장·그림 | 실성과·최종 통계·전체 화면·20페이지 보고서·전체 Compose |

현재 데모의 `toy_policy`는 PPO가 아니다. 데모 SHAP을 PPO나 MVO 의사결정의 설명으로 표시하지 않는다. 합성 영업일은 미국·한국 거래소 달력을 대신하지 않는다.

## 명세와 연결할 때 주의할 차이

| 항목 | 상세 기준서의 목표/원안 | 현재 코드와 연결 방법 |
| --- | --- | --- |
| 시장 가격 | long 형태 market_daily.parquet, 자산·시각·품질 필드 | 현재 입력은 날짜×자산 wide 가격표+manifest. 변환 시 순서·시각·단위를 보존하는 어댑터 필요 |
| 결과 파일 | metrics/anova/tukey/설명 등 개별 파일과 공통 키 | 현재 evaluation.json과 실행별 ledger/weights/decisions, plots 사용. 파일명이 같아도 목표 모든 필드 구현을 뜻하지 않음 |
| Holm 결측 처리 | 미실행 p는 공개 null, 내부 가족 5개 보정에만 1 대입하는 원안 | 현재는 하나라도 검정 불가하면 전체 incomplete, Holm 생략. 원안 방식은 미구현이며 최종 실험 전 처리 방식 고정 필요 |
| 부트스트랩 도구 | 원안은 arch.bootstrap 제안 | 현재 NumPy로 해당 원형 블록 재표집 방식 구현. 문서 때문에 arch를 추가 설치할 필요 없음 |
| SHAP seed | 최종 설명 20260926, 재계산 20260927 | 함수 기본값은 11. 최종 실행 시 명시적 전달·안정성 비교 필요 |
| SHAP 일치 검사 | 실제 정책 기록과 설명 함수 차이 ≤1e−6 | 현재 반복 호출 결정론 검사와 가산 오차 ≤1e−3 검사. 실제 RL 기록과의 비교를 대신하지 않음 |
| 역사 태그 시각 | simulated_available_at과 실제 generated_at 분리 | 현재 RiskTag에는 별도 simulated_available_at 필드가 없음. historical_replay mode와 available_at을 사용하므로 목표 스키마 전환·추적 정보 추가 필요 |
| 자료 부족 상태 | 보고 규격 insufficient_sample | 현재 통계 함수는 insufficient_data 사용. 변환 시 reason 보존 |
| 정의 불가 지표 | null+reason | 현재 지표는 undefined 상태 포함. 정상 0으로 바꾸지 않음 |
| 설명 미준비 | 알려진 결정은 incomplete, 없는 결정은 not_available | 현재 HTTP는 각각 409, 404. 파일 미준비는 503. 최종 응답 스키마에 의미를 일관되게 연결 |
| 실행 메타데이터 | dataset/feature/spec/code/model/execution/risk 버전 | 모든 목표 필드가 저장되는지 실연동 때 검사. 문서 기준 버전을 임의로 기존 결과에 소급 부여하지 않음 |

## 자산·통화 관련 보류 사항

[팀 전달 자료](team_handoff.md)의 Data Pipeline 확인 기록은 **2026-09-26 특정 커밋** 기준이다. 상대 저장소의 최신 상태를 이번 문서화에서 다시 확인한 것은 아니다.

- 기준 원안: 미국 ETF 10개, USD, S&P 500 가격지수와 미국 일별 RF.
- 당시 Data Pipeline: 미국 8개+한국 4개, USD/KRW 혼합.
- 처리: Data Pipeline 종목을 임의로 변경하지 않는다. 자산·기준통화·환율·거래 달력·정보 마감·벤치마크/RF를 합의한 후 기준 버전을 갱신한다.
- 미국 연구안의 가격 기간·비용률·초기자산 숫자가 존재한다고 해서 혼합 시장 평가가 자동으로 성립하지 않는다.
- 정규화된 returns.parquet를 성과 계산에 바로 넣지 않는다. 정규화 전 가격과 비용 차감 후 계좌 원장을 사용한다.

## 완료를 보고할 때

1. 코드·합성 데이터 테스트 통과 여부.
2. 실제 입력 계약과 미래 정보 누수 검사 여부.
3. 실제 모델·기준 전략·통계·SHAP 실행 완료 여부.
4. 수치 목표 달성 여부와 미달 원인.
5. API·화면·보고서에 같은 결과가 반영됐는지.

이 다섯 상태를 각각 보고한다. 이전 테스트 기록은 [로드맵](roadmap.md), 실행법은 [저장소 README](../README.md)를 확인한다.

교육용이며 실제 투자 조언에 사용할 수 없다. 백테스트 성과는 미래 수익을 보장하지 않는다.

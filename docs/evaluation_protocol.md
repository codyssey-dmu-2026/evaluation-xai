# 평가 규칙 v0.1 — 구현 기준

## 과제 필수조건

- 실제 자산 10개 이상·수정주가 5년 이상, 로그 수익률·정규화.
- PPO 보상 3종·최소 100,000스텝, 4년 학습→1년 테스트·최소 2개 구간 완전 재학습.
- 수수료 0.015%, 슬리피지 0.05%, MDD 15% 초과 시 학습 에피소드 종료.
- MVO 252일 공분산·비중 합1·0~40%·월간/분기·SciPy 최적화 수렴 확인.
- 12개 지표·시장/동일가중/MVO 비교, SHAP Summary/Force Plot.
- ANOVA 3종 F/p/η², p<.05이면 Tukey. 비유의성 원인·효과크기 분석 허용.
- 성능 기준: 동일가중 대비 Sharpe +0.2, 시장 대비 누적수익률 +10%p.

## 내부 구현 선택

- 기본 WF2022~2025: 앞선 4개 달력연도로 학습. 실제 달력·범위 완전성은 실자료 통합 시 검사.
- 데모는 2017~2025 영업일·가상 자산 10개. 실제 NYSE/KRX 거래일이 아니다.
- MVO 목적 최소분산, MVO/동일가중 월간 리밸런싱. 공분산은 회계상 단순수익률로 계산.
- 관측용 로그수익률과 회계용 단순수익률 구분. 자산별 로그수익률 비중합으로 포트폴리오 복리를 계산하지 않는다.
- 전일 종가까지 이력으로 결정→다음 거래일 종가 가상 체결. 가용시각·혼합 시장 실거래 제약은 아직 미연결.
- 비용=(매수·매도 금액 절댓값 합)×0.00065. 비용 후 비중 방정식을 풀어 음수 현금 방지.
- MDD는 초기자산 포함 고점 대비 양수 낙폭. 15% **초과** 시 다음 종가 청산→남은 테스트 기간 현금 유지. 현금 이자0.
- 이 백테스터는 Gym 학습 환경이 아니다. 학습 종료와 평가 원장 중단을 구분한다.
- 구간별 초기자산100,000·마지막 종가 청산비용 포함. 기간별 지표와 월별 통계 별도 저장.
- 40%는 목표 비중 상한. 보유 중 가격 변동으로 생긴 초과를 매일 교정하지 않는다.
- MVO 최적화 실패는 동일가중 대체+fallback 원인 기록. 데이터 부족은 오류.

## 12개 지표 정의

r=비용 차감 후 일별 단순수익률, b=동일 날짜·통화 벤치마크 단순수익률,
rf=일별 단순 무위험수익률. 0.01=1%, 연환산252거래일.

| 지표 | 계산 |
| --- | --- |
| 누적수익률 | 최종자산/초기자산−1 |
| CAGR | (최종/초기)^(1/실제경과연수)−1; 연수=경과일/365.25 |
| 연환산 변동성 | 표본표준편차(r,ddof=1)×√252 |
| VaR95% | 손실−r의 95% 선형 분위수 |
| CVaR95% | −r≥VaR인 관측 평균, 경계 동점 포함 |
| MDD | 초기자산 포함 자산곡선 최대 양수 낙폭 |
| Sharpe | 평균(r−rf)/표본표준편차(r−rf)×√252 |
| Sortino | 평균(r−rf)/√평균(min(r−rf,0)²)×√252 |
| Calmar | CAGR/MDD |
| Alpha | (r−rf)=α+β(b−rf)+오차 OLS의 일별α×252 |
| Beta | 위 회귀의 β |
| Information Ratio | 평균(r−b)/표본표준편차(r−b)×√252 |

0분모·관측 부족은 undefined/null+이유. 데모 RF=0은 실제 평가에 자동 적용하지 않는다.

## 통계

- 월별 복리수익률. 불완전 월은 입력 단계 확인. PPO seed11/22/33의 동일 월 평균.
- seed 누락은 오류. MVO/EW를 seed 수만큼 복제하지 않는다.
- One-way: 보상 R1/R2/R3, 전략 PPO/MVO/EW. `strategy` 열에 비교할 그룹명 입력.
- Two-way: 전략×국면, Sum 대비·Type III. 국면은 월 시작 전60거래일 시장수익률 ±5%.
- 그룹 최소12개월, Two-way 각 셀 최소6개월은 내부 기준. 부족하면 insufficient_data.
- η²=효과 제곱합/중심화 총제곱합. 불균형 Type III 효과크기들의 합을 1로 해석하지 않는다.
- 원시p<.05→Tukey. Two-way는 모든 전략×국면 셀을 하나의 비교군으로 취급; 상호작용 해석 별도.
- `mission_anova`는 3검증의 5개 총괄 효과에 Holm 보정p 추가.
- Levene·잔차 Shapiro 진단. 자기상관·동일 월 대응구조 때문에 독립 표본의 확증 검정으로 주장하지 않는다.
- 보완: 대응 월별 **평균수익률 차이**의 연도 내 원형 블록 부트스트랩5,000회. 3개월 기본,1/6개월 민감도. Sharpe 차이 검정이 아니다.

## SHAP

- 대상: 보호규칙 전 정책 비중. 실제 환경의 action→weight 변환까지 포함.
- 배경: 해당 학습 구간 rollout32개. 테스트 데이터로 배경/스케일러 fit 금지.
- 입력을 겹치지 않는 그룹으로 분할. 현재 비중 전체 등 결합 제약 변수는 함께 묶는다.
- 그룹 교체 기반 interventional Permutation SHAP. 배경/상관구조에 민감하며 인과·투자 타당성 증명이 아니다.
- 기준값+기여도 합과 예측 차이1e−3 이하, 결정론적 호출.
- 보호규칙 변경은 정책/최종 비중·규칙ID·출처 로그로 따로 설명.
- 현재 API는 사전 계산 조회. 전체 설명 커버리지·신규 설명5초 성능·배경seed 안정성은 실제 모델 입수 후 검증.

교육용이며 실제 투자 조언에 사용할 수 없다. 백테스트 성과는 미래 수익을 보장하지 않는다.

# 평가 규칙 — 문서 위치 안내

평가 문서를 요약·상세·구현 상태로 분리했다. 기존 링크로 방문한 경우 아래 순서로 읽는다.

1. [평가 기준 요약](evaluation_criteria.md): 과제 필수조건과 Evaluation 기본값, 성능 목표 판정.
2. [상세 기준서](evaluation_specification.md): 지표 계산식·Walk-Forward·거래·통계·SHAP·목표 입력 계약.
3. [현재 구현 상태와 차이](implementation_status.md): 코드에 반영된 범위와 남은 검증.
4. [팀 전달 자료](team_handoff.md): 지금 코드와 연결할 자료와 연동 주의점.

이전 v0.1 구현 요약은 저장소 Git 이력에 남아 있다. 현재 기준과 다른 규칙을 중복 유지하지 않기 위해 이 파일은 안내만 제공한다.

전체 문서의 적용 범위와 변경 기록은 [문서 안내](README.md)를 확인한다.

교육용이며 실제 투자 조언에 사용할 수 없다. 백테스트 성과는 미래 수익을 보장하지 않는다.
